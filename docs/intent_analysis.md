# SupportSense Intent Analysis

## 1. Purpose

Sprint 1 performs exploratory analysis of the BANKING77 customer-support
intent classification dataset.

The purpose of this analysis is to understand:

- the number and size of customer-support intents
- differences in text length between intents
- vocabulary size across intents
- vocabulary overlap between intents
- potentially difficult intent pairs for later classification models

The analysis is exploratory and does not perform model training.
